# Appliance Energy Forecasting

24-hour-ahead forecasting of household appliance energy consumption, comparing
statistical, machine-learning, and foundation-model approaches on the
[UCI Appliances Energy Prediction dataset](https://archive.ics.uci.edu/dataset/374/appliances+energy+prediction).

Four approaches are evaluated on an identical, chronological 14-day held-out
test period using a common rolling-window protocol:

| Model | RMSE (Wh) | MAE (Wh) | MAPE | sMAPE |
|---|---|---|---|---|
| **SARIMAX(1,0,6)x(1,1,1,24)** | **328.6** | 214.2 | 33.1% | 29.7% |
| **Chronos-Bolt-Small (zero-shot)** | 334.9 | **201.8** | **25.8%** | **26.0%** |
| XGBoost (direct multi-horizon) | 341.2 | 240.8 | 39.6% | 34.0% |
| Mean (benchmark) | 391.2 | 296.1 | 53.6% | 46.0% |
| Weekly Seasonal Naive (benchmark) | 404.9 | 254.6 | 37.1% | 32.5% |
| Daily Seasonal Naive (benchmark) | 455.8 | 288.6 | 43.8% | 35.5% |
| Naive (benchmark) | 584.7 | 512.0 | 113.4% | 65.4% |
| Drift (benchmark) | 586.1 | 513.6 | 113.8% | 65.5% |

Full methodology, diagnostics, and discussion are in report.

## Running

### Option A: the notebook (recommended for exploration/grading)

Open `notebooks/01_09_full_pipeline_thru_discussion.ipynb` in Jupyter or
Google Colab and run all cells top to bottom. The notebook downloads the
dataset itself no manual upload needed. It contains the full narrative,
all diagnostic plots, and the answers to the assignment's discussion
questions inline.

**Note:** the SARIMAX AIC grid search cell takes ~15-20 minutes (147 model
fits, by design per the assignment spec). The Chronos section requires an
unrestricted internet connection to download pretrained weights from
HuggingFace Hub on first run (works on Colab; will fail in network-locked
sandboxes).

### Option B: the pipeline script (recommended for reproduction/CI)

```bash
# Download the dataset first
mkdir -p data
curl -L -o data/energydata_complete.csv \
  https://raw.githubusercontent.com/LuisM78/Appliances-energy-prediction-data/master/energydata_complete.csv

# Full run (~20-25 minutes, includes SARIMAX grid search + Chronos)
python run_pipeline.py

# Fast run (~2-3 minutes): skip the grid search and the foundation model
python run_pipeline.py --skip-sarimax-search --skip-chronos
```

This reproduces every number in the results table above and writes all
figures/CSVs to `outputs/`, culminating in `outputs/final_comparison_rolling.csv`.

## Key findings

- Appliance energy use is strongly seasonal at two nested periods (24h and
  168h/weekly); naive momentum-based forecasts (Naive, Drift) perform poorly.
- A correctly-specified SARIMAX model, using only the target series itself,
  achieves the best RMSE and is highly competitive across all metrics.
- **Chronos, used purely zero-shot with no training on this dataset at all,
  matches or beats every other model on MAE/MAPE/sMAPE** a striking result
  for a general-purpose foundation model on an unfamiliar domain.
- A feature-based XGBoost model, despite the richest feature set (lags,
  rolling stats, cyclical time encodings, weather/sensor covariates), placed
  third and its comparison is not fully like-for-like, since it was given
  perfect future weather/sensor values that the other two models were not
  (see the report's Discussion Q5 for a full treatment of this caveat).
- Full methodology, diagnostics, limitations, and the assignment's 6
  discussion questions are answered in depth in report.
